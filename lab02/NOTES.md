Рабочая папка - это обыная папка на вашем компьютере, где вы видете и редактируете файлы.
Индекс - это промежуточное хранилище. Сюда попадают изменения из рабочей папки, которые планируете сохранить в следующем коммите
Коммит - это сохранённый "снимок" состояния индекс в истории проекта. КОммит попадает в базу данных Git и становится частью истории

Git -  это система контроля версий, программа которая работает локальнона компьютере и отслеживает изменения в файлах.
GitHub - это веб-сервис для храниния Git репозиториев в облаке
git diff сравнивает Рабочию папку и Индекс. Он показывает, что вы изменили в файлах, но ещё не добавили в область подготовки
git diff --staged сравнивает Индекс и Последний коммит. Он показывает, что именно уйдёт в следующий коммит
